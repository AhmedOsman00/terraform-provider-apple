## apple signing clean

Remove the keychain --ephemeral-keychain created

```
apple signing clean [flags]
```

### Options

```
  -h, --help              help for clean
      --keychain string   the keychain to remove (default: the one --ephemeral-keychain creates) (env APPLE_KEYCHAIN)
```
